一、项目文件清单
--------------------------------------------------------------------------------
  index.html              APP 入口（已配置 PWA，支持 iOS 添加到主屏幕）
  data.js                 数据源配置（榜单、成分、评论、图表、来源清单）
  manifest.webmanifest    PWA 配置
  icon-192.png / icon-512.png / apple-touch-icon.png   应用图标
  gen_icon.py             图标生成脚本（如后续要换图标颜色/样式可再跑）
  build_app.py            把原原型 html 转换为本工程的脚本（开发用）

二、如何部署 + iOS 添加到主屏幕
--------------------------------------------------------------------------------
  1. 把整个「美妍研」文件夹上传到任意静态托管：
     • GitHub Pages
     • Vercel / Netlify（直接拖拽文件夹即可）
     • 腾讯云 COS / 阿里云 OSS（开启静态网站）
     • 你自己的 Nginx/Apache 服务器
     注意：iOS 的「添加到主屏幕」要求页面通过 HTTPS（或 localhost）访问。

  2. 用 iPhone 的 Safari 打开托管后的 index.html 链接。

  3. 点击下方分享按钮（方框带箭头）→「添加到主屏幕」。
     系统会自动使用 apple-touch-icon.png 作为图标，名称显示「美妍研」。

  4. 以后从主屏幕点击图标，就会以「独立 App」形式全屏打开，无 Safari 地址栏。

三、数据层说明（重要）
--------------------------------------------------------------------------------
  当前 APP 里看到的数据，全部是写在 data.js 中的「演示数据」。
  要接入真实数据，不需要改 index.html 里的任何逻辑，只需要：

    ① 整理好你的真实数据；
    ② 按 data.js 中注释的字段格式，替换对应数组（RANK / ING / REVIEWS / CHARTS / PRICE）；
    ③ 重新上传 data.js 即可。

六、常见问题
--------------------------------------------------------------------------------
  Q：能不能直接用本地文件「添加到主屏幕」？
  A：iOS 不支持把 file:// 本地文件添加到主屏幕。必须先上传到 HTTPS 网站。

  Q：data.js 会不会被缓存导致改了不生效？
  A：静态托管默认会缓存 JS。部署后如修改 data.js，可在链接后加 ?v=2 强制刷新，
     或在托管后台设置禁用缓存。

  Q：图标可以换吗？
  A：可以。替换 icon-192.png / icon-512.png / apple-touch-icon.png 三张即可；
     也可以用 gen_icon.py 重新生成不同配色的图标。
